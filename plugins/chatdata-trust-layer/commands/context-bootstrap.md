# Context Bootstrap

Use this when a workspace has little or no approved context and needs the first reusable setup packet.

Start with `/chatdata:onboarding`. Then create or propose the smallest useful artifacts:

- top-10 metrics
- source inventory
- owner map
- first recurring answer paths
- caveats and freshness rules
- first proof receipt

If a customer-owned repo is available, use `/chatdata:bootstrap-repo`. If MCP context is available, write through MCP first so every plugin and Slack surface sees the same state.
